# Maharashtra Digital Hub

Create a single-page visual prototype for a Maharashtra Government digital services portal.

First visit and use this website as the main visual reference:
https://mahabocw.in/en/

Match its overall Maharashtra Government / Maha BOCW visual identity — clean government-style layout, official-looking header, typography, colors, spacing, navigation and footer.

Main Concept

The page is a central portal for accessing different external websites, but the links are presented in an OTT-platform-inspired card layout.

It should feel like:

Maharashtra Government website + modern OTT-style portal cards

Do NOT make it look like Netflix or a SaaS dashboard. Keep it formal, clean and suitable for a government website.

Header

Create a government-style header inspired by Maha BOCW with:

Maharashtra Government / महाराष्ट्र शासन branding

Maharashtra Government emblem/logo area

Portal title: Maharashtra Government Digital Services

English / मराठी language option

Search icon

Simple navigation

Use the official Maharashtra Government logo/emblem if available from the reference website. Do not invent a logo.

Main Section

Add a short heading:

Maharashtra Government Digital Services

Subtitle:

Access education, worker welfare, skill development and other useful services through one platform.

Then create the main portal-card area.

OTT-STYLE CARD SECTIONS

Create horizontal card rows similar to OTT browsing.

Education & Learning

Cards:

Unacademy

Online Learning

Digital Education

Study Resources

Worker Services

Cards:

Worker Welfare

Worker Services

Worker Benefits

Worker Information

Skill Development

Cards:

Skill Development

Training Programs

Vocational Learning

Courses

Government Services

Cards:

Maharashtra Government

Aaple Sarkar

MahaOnline

Government Services

Each section should have a heading and a row of cards.

Card Design

Make the cards visually attractive but government-oriented.

Each card should contain:

Logo/image area

Portal name

Short description

Small "Visit Portal →" text

Example:

UNACADEMY

Online learning and educational resources

Visit Portal →

Cards should have subtle shadows, borders and a small hover effect.

IMPORTANT FUNCTIONALITY

Only implement basic click functionality for now.

When the Unacademy card is clicked, open:

https://unacademy.com/

For the other cards, use placeholder links for now.

Keep the URLs easy to change later.

Visual Style

Use the Maha BOCW website as the primary reference for:

Government header

Colors

Typography

Navigation

Section styling

Footer

Overall spacing

Keep the background light and professional.

Avoid:

Dark mode

Neon colors

Excessive gradients

Glassmorphism

Gaming-style UI

Excessive animations

Overly rounded cards

Startup/SaaS dashboard styling

Footer

Create a simple official-looking Maharashtra Government footer with:

Government of Maharashtra

Useful Links | Contact | Privacy | Disclaimer | Accessibility

© Government of Maharashtra. All Rights Reserved.

Responsive

Make the prototype responsive for desktop and mobile.

IMPORTANT

This is a FIRST-ROUND UI CONCEPT / DEMO, so prioritize the visual design and overall look over advanced functionality.

Do not build authentication, database, admin panel, complex filtering, backend APIs or other advanced functionality.

The goal is to create a polished screen that we can show to our team as the initial design concept and then enhance in the next iteration.
